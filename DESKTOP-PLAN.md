# 网文工具箱桌面端实施方案

> 创建时间：2026/06/26
> 项目代号：oh-story-desktop
> 技术栈：Electron + Vite + React + TailwindCSS + TypeScript

---

## 一、现状分析

当前项目 `oh-story-claudecode` 是 Claude Code 技能套件，核心特点：

| 维度 | 现状 |
|------|------|
| 运行载体 | Claude Code 的 `/story` 命令，技能以 Markdown + JS 脚本形式存在 |
| 技能类型 | 扫榜（浏览器 CDP 抓取）、拆文、写作、去 AI 味、封面生成 |
| 主要语言 | JS（Node.js 脚本）+ Markdown（技能定义）+ Claude Agent Prompt |
| 无现有服务端 | 所有逻辑都是"Claude 读取技能文件 → 执行"的被动模式 |
| 发布方式 | `npx skills add` 装到用户项目目录 |

## 二、核心设计决策

### 2.1 命令调用方式：混合方案

根据命令特性和调用频率，划分为两类：

| 类型 | 判断依据 | 调用方式 |
|------|----------|----------|
| **CLI 包装类** | 低频、逻辑复杂但无状态依赖 | `claude --print "/story-xxx"` |
| **API 直调类** | 需要进度反馈、高频重复、任务持久化 | preload → IPC → Node.js 脚本直接调用 |

#### 命令分类表

| 命令 | 类型 | 原因 |
|------|------|------|
| `/story-setup` | CLI 包装 | 低频，逻辑固定，无状态 |
| `/story-import` | CLI 包装 | 低频，流程固定 |
| `/story-cover` | CLI 包装 | 逻辑在 skill prompt 里，不易拆分 |
| `/story-deslop` | **API 直调** | 高频（每次写完去味），需即时反馈 |
| `/story-review` | CLI 包装 | 低频，逻辑复杂 |
| `/story-long-scan` | **API 直调** | 需要进度条、失败重试 |
| `/story-long-analyze` | **API 直调** | 超长任务，需要暂停/恢复 |
| `/story-long-write` | **API 直调** | 需要实时流式输出 |
| 版本检查 | **API 直调** | 查 GitHub API，超时需处理 |

## 五、关键技术实现

### 5.1 CLI 包装命令执行

```typescript
// electron/runners/cli-runner.ts
import { spawnSync } from 'child_process';

export async function runSkillCommand(cmd: string): Promise<string> {
  // 例：claude --print "/story-setup"
  const result = spawnSync('claude', ['--print', cmd], {
    cwd: projectRoot,
    encoding: 'utf-8',
    timeout: 120_000,
  });
  return result.stdout || result.stderr;
}
```

### 5.2 技能脚本直接调用

```typescript
// electron/runners/script-runner.ts
import { spawnSync } from 'child_process';

export async function runSkillScript(scriptPath: string, args: string[]) {
  // 例：node skills/story-deslop/scripts/normalize-punctuation.js
  return spawnSync('node', [scriptPath, ...args], {
    encoding: 'utf-8',
  });
}
```

### 5.3 任务队列（Bull + SQLite）

```typescript
// electron/services/task-queue.ts
import { Queue } from 'bullmq';
import { LowSync } from 'lowdb';

// 使用 better-sqlite3 持久化（无需 Redis）
const queue = new Queue('oh-story-tasks', {
  connection: new LowSync(new SQLite('./task-queue.json')),
});

// 任务类型
type TaskType =
  | { type: 'cli'; cmd: string }
  | { type: 'script'; script: string; args: string[] }
  | { type: 'scan'; platform: string; 榜单: string };
```

### 5.4 Preload 安全桥接

```typescript
// electron/preload.ts
contextBridge.exposeInMainWorld('electronAPI', {
  // CLI 命令
  runCli: (cmd: string) => ipcRenderer.invoke('cli:run', cmd),

  // 技能脚本
  runScript: (script: string, args: string[]) =>
    ipcRenderer.invoke('script:run', script, args),

  // 任务队列
  queueTask: (task: TaskType) => ipcRenderer.invoke('task:queue', task),
  getTasks: () => ipcRenderer.invoke('task:list'),
  cancelTask: (id: string) => ipcRenderer.invoke('task:cancel', id),

  // 项目
  selectProjectDir: () => ipcRenderer.invoke('dialog:selectDir'),

  // 任务事件订阅
  onTaskProgress: (cb: (progress: number) => void) =>
    ipcRenderer.on('task:progress', cb),
});
```

## 八、风险与注意事项

1. **Claude CLI 冷启动**：CLI 包装命令每次有 2-5 秒启动开销，UI 需有 loading 状态
2. **CDP 端口占用**：多个平台扫榜可能需要多个 Chrome 实例，需端口管理
3. **技能脚本路径**：script-runner 需动态定位 `skills/` 目录，兼容全局安装和本地项目
4. **Windows 路径处理**：所有文件路径使用 `path.resolve` + `/` 分隔符
5. **任务队列 SQLite 并发**：BullMQ 的 SQLite adapter 在 Windows 下写锁可能冲突，生产环境建议迁移到 Redis
